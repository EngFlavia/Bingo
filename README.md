# App Bingo

Aplicativo para sorteio de números em jogos de Bingo. Mantém a visualização dos últimos números sorteados e pode ser espelhado em uma TV, monitor ou projetor para facilitar o acompanhamento pelos participantes.

Application for drawing numbers in Bingo games. It keeps track of the most recently drawn numbers and can be mirrored to a TV, monitor, or projector, making the game easier for all participants to follow.

## Recursos / Features

- Sorteio de números de Bingo / Bingo number drawing
- Exibição dos números já sorteados / Display of previously drawn numbers
- Atualização em tempo real entre as telas / Real-time updates across screens
- Opção para reiniciar o jogo / Option to reset the game
- Tela de projeção para dispositivos maiores / Projection screen for larger displays
